# StreamRAG 精读：从在线边界到历史证据

Junlin Xie 等，CVPR 2026。核心流程是视频到达时切段并生成事件描述，问题到达时选择哪些描述进入回答上下文。[本地正文](StreamRAG_CVPR2026.pdf) · [本地补充材料](StreamRAG_supplement.pdf) · [CVF 出版页](https://openaccess.thecvf.com/content/CVPR2026/html/Xie_StreamRAG_Enhancing_Real-Time_Video_Understanding_with_Retrieval_Augmentation_CVPR_2026_paper.html)

## 1. Streaming Event Segmentation（正文 §3.2、§4.1）

逐帧提取 ViT 的 CLS 特征，计算相邻帧的语义相似度序列。窗口参数 w=8。窗口内每个候选位置 i 对应一个相似度 c_i，左右的相似度峰值分别记为 L、R。谷深 d_i=(L+R)/2−c_i，判据为 d_i > mean(d)+0.7×std(d)。均值和标准差都来自当前窗口内的谷深。0.7 是标准差的倍率。论文将此谷深计算归于参考文献 [27] VideoLLaMB。§3.2 写的是 CLS 语义相似度，没有像 §3.4 的文本检索一样显式写出余弦公式。采用 L2 归一化加点积需要记为复现选择。

上一个边界是 b0，本次边界是 b，则输出帧 b0+1 到 b，下一段从 b+1 开始，窗口向后推进。w 控制判断所用的局部历史，event 可以跨过多个窗口。表 4 报告 SES 约 32 帧；不能据此设置每 32 帧强制切分。

以超声示意：切面转换前后画面都相对稳定，左右峰为 0.98 和 0.96，转场相似度为 0.80，谷深为 0.17。如果窗口谷深均值为 0.05、标准差为 0.04，此时阈值为 0.078，可以触发。这些数用于解释公式。持续运动会改变局部参照和阈值，因此仅有一个 0.80 无法决定切分。

## 2. 哪些细节会让两个复现得到不同边界

候选点右侧的峰只能使用到当前时刻为止的帧。即使最后选中第 b 秒，确认时刻也可能更晚，论文未给出固定延迟。写入我们的 event 索引时应分开保存 boundary_s 与 available_at_s，QA 在 T 秒只能取 available_at_s ≤ T 的记录。生成 caption 若再增加延迟，文本可用时刻还需单独记录。

正文和补充材料给出了 w 和标准差倍数。未核实到作者的公开实现，无法确定峰的精确搜索顺序、同窗多个越阈点的选择、并列峰/端点处理、标准差自由度、长时间无峰或视频尾段的处理。式中窗口下标从 t−w 到 t，文字称宽度为 w；实现时也要固定端点计数方式。论文没有为超声指定最短段长。

## 3. 一段 event 如何成为可检索知识（正文 §3.3–3.4）

1. 用当前 event 的视频帧生成 caption。以上一条 caption 作为候选文本，在当前视觉条件下并行验证旧 token 的下一词概率。首次出现充分大的 log 概率下降时保留此前前缀，从分歧处自回归生成剩余内容，再将新 caption 追加进知识库。式 10 取前 20 个位置的平均 log 概率 μ；当 μ−ℓ 超过 max(0.85×|μ|, 1) 时判为分歧。该窗口与视觉切分的 w=8 属于不同模块。
2. 问题到达时，文本 LLM 为问题对当前画面的依赖程度打分 St；文本编码器用余弦相似度寻找最相关的 3 条历史 caption，其均值为 Sr。Sc=0.5×St+0.5×(1−Sr)。Sc 高时仅取最新一条；中档取相关性 Top-3，低档取 Top-5。第一档依据时间，后两档依据语义。原文用 θ1、θ2 表示档位分界，§4.1 给出了档位深度，未给出两个分界数值。补充材料提供 caption 和时间依赖性分类的提示词。
3. 把选中的文字描述加入回答上下文。论文评估的是这套检索增强方法带来的 QA 表现。我们的系统取回历史采样帧，另外每秒决策 WAIT/ANSWER；两套系统可只对照边界检测，让其余条件保持一致。

## 4. 实验给出的证据（正文表 3、4）

| 知识库更新 | 实时问题 R-Avg | 历史问题 B-Avg |
|---|---:|---:|
| 固定 16 帧 | 65.33 | 49.75 |
| 固定 32 帧 | 68.98 | 50.04 |
| SES，约 32 帧 | 69.96 | 53.08 |

与固定 32 帧相比，SES 提升 0.98 和 3.04 个百分点，这是下游 QA 分数。论文表 3 中，约 18% 的 caption token 复用将该表的延迟从 15.24 秒降至 11.12 秒。这个量不能作为边界确认延迟或我们每秒 WAIT 决策的实测值。

在我们的 10 个视频上检验该规则时，可先从已缓存逐秒特征生成独立的候选 event 索引，保留当前模型和历史取帧预算，分别测段长分布、确认延迟及历史证据窗口召回。使用 Qwen 空间 token 均值代替论文的 ViT CLS 时，需要显式记录特征差异。超声中的局部征象可能在同一稳定切面内出现，近期帧分支仍应逐秒可见。
