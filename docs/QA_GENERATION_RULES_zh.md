# 超声视频 QA 生成与审核规则

11 字段版 · 2026-11-25

将带原声的超声视频、视频 ID 和源视频时间戳交给模型，让模型自主发现值得回答的问题。可听讲解或参考 ASR 理解扫查背景。每题都须静音回看证据片段，确认问题所问的事实在画面中可见。每个视频输出一个 `<video_id>.jsonl` 文件，每行一道英文候选 QA。生成时使用配套的[英文提示词](QA_GENERATION_PROMPT_en.md)。

## 1. 内容范围

| 优先内容 | 考察重点 |
|---|---|
| 器官与解剖结构 | 当前出现了什么器官、结构在哪里、与周围组织有什么关系 |
| 超声影像特征 | 形态、边界、回声明暗、声影、可见的多普勒信号 |
| 切面理解 | 当前是什么可辨认的切面、切面如何随扫查变化 |
| 扫查过程 | 哪些结构先后出现、何时进入或离开视野、是否再次出现 |
| 探头操作 | 可见的移动、旋转、倾斜，以及对应的影像变化 |
| 介入操作 | 仅在相关视频中考察针体、针尖及其与目标结构的关系 |

超声图像本身可以构成充分证据，不要求同时显示设备、探头或操作者。纯超声片段中的器官、结构、切面及其出现、消失、再次显示和形态变化均可用于 QA。仅当题目考察探头或操作过程时，才需要相应操作画面；针尖不是必选目标。

不要求每个视频覆盖所有内容。无法可靠命名结构时，可以描述可见特征，也可以舍弃该题。描述操作和影像变化同时发生，不等于已经证明因果关系。

## 2. QA 类型

按画面中的独立观察点选题，再根据参考答案要完成的任务选一个主类型。WAIT 或 ANSWER 由提问时的证据决定。同一视频可以只贡献一种题型。

| 类型 | 问什么 | 提问时的决策 |
|---|---|---|
| 当前观察 `current_observation` | 当前画面显示什么，包括同一帧中两个结构的位置或明暗关系。 | 当前画面足够时 ANSWER |
| 历史回忆 `history_recall` | 本次扫查早先出现了什么？去掉历史后应缺少关键事实。 | 所需历史已出现时 ANSWER |
| 时序比较 `temporal_comparison` | 在有明确对应关系的两段影像中，同一结构或征象有什么相同或不同？答案分别描述两段。 | 两段均已看到即可 ANSWER；还缺第二段才 WAIT |
| 事件通知 `event_notification` | 操作者希望系统在什么可观察条件成立时提醒？ | 按提问当下的证据决策；只有实际需要等待的题计入主动题 |

用“刚才加压前”“患者侧身后那次”等有唯一含义的扫查事件定位历史。精确历史秒数留在标注里；操作者已显式设书签或任务本身要求按时间查找时，才写入问题并标记这种条件。遮掉未来画面重读问题，确认当时已有的信息足以自然提出这个问题，事件最终没有发生也是合理结果。模型可以自行提出观察、回忆或比较问题，问句无需模仿医生的口吻。问句可以指定监测目标，但不预告结果、历史答案或将出现的方向。

“等静脉重新张开时提醒我”归为事件通知；“等它重新张开时，比较其形状与加压前有何不同”归为时序比较，答案需要描述前后两段。

## 3. 事件通知的规则

优先选择以下触发目标：

- **器官或结构出现**：看到心脏、肾脏、膀胱或某个可辨认结构。
- **特定切面出现**：出现能够可靠辨认的目标切面。
- **目标再次出现**：扫查离开后重新回到某个器官。
- **影像状态变化**：目标离开视野、切面切换，或出现明确可见的变化。
- **介入相关事件**：仅在介入视频中使用针尖等目标，不将其作为默认目标。

必须明确区分以下条件：

| 条件 | 判定含义 |
|---|---|
| 可以辨认出器官 | 已有足够影像证据确认器官身份，不要求完整显示 |
| 器官完整显示 | 规定的完整显示范围已经满足，要求高于仅辨认身份；必须事先明确判据 |
| 目标切面出现 | 满足该切面的可见判据，不能仅凭字幕命名 |

屏幕写着“Heart”，不等于超声画面已经能够辨认出心脏。

## 4. WAIT 与 ANSWER 标注

- **提问时条件已经满足**：立即 `ANSWER`，不制造等待。
- **提问时未满足，之后满足**：先 `WAIT`，在首次确认满足条件时 `ANSWER`。
- **截至视频结束仍未出现**：只有完整检查了提问后的相关片段，才能标为“截至结束未触发”的负例；不编造肯定答案或触发时刻。此类负例不意味着目标在未来永远不会出现。
- **画面模糊、无法判定**：标为不确定并复核，不能直接当作“目标不存在”。

每道题只输出以下 11 个字段。抽帧覆盖、复核状态等信息另记在审核报告中。时间使用源视频秒数，裁出的片段保留原视频偏移。判据、参考答案及证据窗口供监督和复核使用。

| 字段 | 填写规则 |
|---|---|
| `video_id` | 原视频 ID。 |
| `question_id` | 视频内稳定且唯一的题号，与视频 ID 一起定位这道题。 |
| `qa_type` | 第 2 节中的一个主类型。 |
| `query_time` | 在已看画面的基础上可以自然提问的时刻。 |
| `question` | 英文问题，聚焦一个有视觉依据的考点。 |
| `decision_at_query` | 提问当下的判断，取 `WAIT` 或 `ANSWER`。 |
| `decision_reason_at_query` | 用英文解释提问当下的判断。WAIT 写当前看到了什么、还缺什么；ANSWER 写当前已有的充分证据。 |
| `trigger_criterion` | 等待题填写可核验的英文触发条件；即时描述题可填 JSON `null`。 |
| `answer_time` | 首次能从画面明确作答的秒数；即时回答时等于提问时间；核实到观察结束仍未触发时填 `null`。 |
| `reference_answer` | 到应答时刻由画面支持的简短英文答案；核实未触发时填 `null`。 |
| `evidence_windows` | 支持判断的最短充分片段，格式为闭区间列表 `[[起始秒, 结束秒], …]`。单个采样点可写为 `[[82, 82]]`；跨时比较按先后给出两端证据；未触发题给出已核查的观察区间。 |

**逐秒核验。** 先确定自然的观察终点。从提问起检查每个整数秒及非整数提问、决策端点，直到首次明确可答或观察结束。用该时刻或更早的最后一帧；对快速运动、短暂变化和重复触发，以原帧率回看边界。讲解若提前说出结论，仍以静音观看时画面首次提供充分证据的时刻为准。过渡模糊的点跳过二元评分；首次触发无法可靠定位时，改写题目或舍弃。

**核实未触发。** 完整查看提问后至观察终点的画面，确认条件始终未满足，才保留 `WAIT` 且两个答案字段均为 `null` 的题。画面缺失或仅查了部分时段的题留待复核。提问时的理由只描述当时的判断，后续时刻需要各自核实。

**等待与记忆分开统计。** 等待时长等于明确应答时间减提问时间。选视频和出题均以可辨认的扫查事件为依据，任何时长的素材都可以贡献有效 QA。标注完成后，如需分析当前 1 FPS、24 帧配置，可将最早合理应答距提问超过 24 秒的题单列统计。先找自然提问点，再沿时间向前找第一次满足条件的证据；已出现又消失再出现时按题义区分首次与再次。保留即时、短等待、长等待和全程未触发题。历史跨度另记应答到必需历史证据的距离，核对它是否仍落在实际短窗口内。按时答对和依赖历史需分别验证。

## 5. 生成与复核顺序

1. **建立事件记录。** 按病例和连续扫查分段。ASR 帮助找到术语和候选动作；静音回看原视频，记录基线、对象、变化和可定位的原始证据。分清实时扫查、回放同一片段、换患者和讲解剪辑。
2. **在提问处暂停。** 根据当时可见的画面，自主写出有价值的英文问句、当下判断及理由，再列出怎样才算目标出现。将“更清楚”等主观描述改成可检查的结构或边界；若多人无法稳定定位首次满足，可在两段画面都已出现后改问比较题。
3. **按前缀复核并查捷径。** 在模型实际抽帧、缩放和裁剪后重看。分别检查只给问题和时钟、只看字幕/标签/操作或布局、遮住文字后看片，是否仍能完成本应依赖超声的判断。注明答案直接泄露、部分提示或无明显提示。靠医学常识或剪辑即可完成的核心题应改写、作对照或剔除；不能仅靠避免解剖名称隐藏文字泄露。
4. **验证长记忆。** 先只给最近 24 帧和原问题，再恢复历史。记录答案中哪一项可由正确历史补足；若最后一段或问句已经给出两端信息，移出长记忆评测。更换为匹配的其他历史片段可作进一步验证。
5. **按含义去重。** 在同一病例、同一事件与重复播放的证据片段中，比较必要证据、触发条件和答案结论。相同事实的复述只计一次。共享事件的题只在考察目标确实不同且有不同判别证据时保留，并标记关联以便按事件汇总。

## 6. 不生成的题目

- Freeze 按钮颜色、菜单切换等纯界面题。
- 读取字幕、标签、箭头颜色即可回答的题。
- 不看视频也能回答的医学常识题。
- 仅凭讲解就断言画面存在某个器官、病变或操作结果的题。
- 从不充分的影像推断疾病、异常血流或操作成功的题。
- 同一个观察反复换措辞的重复题。

字幕和教学标注可以辅助核对，不能替代影像证据。筛选时可问：去掉超声影像及相关操作画面，只保留字幕和界面，这道题是否仍然能答？如果能，通常不应保留。

## 7. 问题与答案的语言

- 训练问题和答案均为英文，中文仅作审阅译文，两者含义保持一致。
- 每题聚焦明确的考察目标，答案简洁，只包含画面支持的判断。
- 区分画面方向与患者身体方向。
- 对识别题，避免在问题中泄露待识别结构的名称；对事件通知题，可以明确指定需要等待的目标器官或结构。
- 不确定的细粒度解剖名称、切面或病理判断，进入专业复核，不强行给出确定答案。

例如，“当可以辨认出心脏时通知我”是在指定检测目标，不构成答案泄露；“这颗心脏是什么器官”则泄露了识别题的答案。

## 8. 数量与质量验收

时长为 T 分钟的视频，以约 4T 道独立 QA 为目标（T 取源视频时长秒数除以 60）。实际题量随有效观察点调整；重复画面或长段讲解可少出，证据丰富时可多出，四类题没有配额。批次报告视频数、独立事件数、独立题数、决策行数、四类题的实际分布，以及即时、长短等待、未触发和待复核的数量。另报等待分布、历史跨度和共享证据比例。覆盖不足应补采合适素材，避免按时长凑数或从一个事件派生整套模板。

结构可自动检查：ID 与视频归属、时间顺序和视频范围、提问决策与应答时刻一致、提问理由已填写、已应答题的证据窗口止于应答时刻或更早、未触发题的两个答案字段均为空。由读者看片核实器官或切面、合理提问、首次充分证据、理由与画面一致性、语义重复和泄露。用于论文核心时机评测时，建议由两位有超声经验的读者隐藏对方标注和候选触发时刻，分别观看截至当前的画面，记录分歧、可接受区间与裁决。训练候选和独立专家复核结果分别报告。

**校准例 CW3TLabogko / C03。** 165 秒提问。165–188 秒仍为短轴，缺少比较所需的心尖窗；189–202 秒显示讲者，没有可判读的超声图；203 秒心尖窗重现，留作过渡；204 秒能比较左室走向。本题的提问理由只写 165 秒时已看到早期参照、仍缺心尖窗；47–52 秒和 203–204 秒分别提供比较所需的早期与后期证据。剪辑与触发相邻，须检查剪辑捷径；关于历史依赖的结论有待最近 24 帧对照验证。

训练与评测按视频划分，同一视频的全部 QA 及其决策行归入同一侧。分别评估能否回答的判断、提前回答、触发后的响应延迟与答案正确性；单独报告未触发负例的误触发情况。

每题进入训练候选集前，检查以下项目：

| 检查项 | 必须满足的要求 |
|---|---|
| 超声相关性 | 考察超声影像或相关操作理解 |
| 证据充分性 | 问题前提和答案都有可定位的画面依据 |
| 时间正确性 | 当前回答不依赖未来画面，触发时刻经过核验 |
| 任务必要性 | 历史题确实需要历史信息，时序题确实需要多个时刻 |
| 模型可见性 | 在训练实际的缩放、裁剪与抽帧后，关键证据仍可辨认 |
| 非重复性 | 与其他题有实质不同的考察目标 |
| 审核透明性 | 分别记录格式检查、视觉复核和专业审核状态 |

同一段证据可以支持不同能力的题，但必须有实质区别。同一视频的 QA 应归入同一数据划分；增加题数不能替代增加视频、受试者和场景的多样性。格式检查通过不代表视觉标注正确，也不代表已经通过医学专家审核。
